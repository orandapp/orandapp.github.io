# اورند | سایت استودیوی اپ‌سازی

سایت ثابت (فقط HTML)، فارسی و انگلیسی، تم تاریک و روشن.

## فایل‌ها
- `index.html`: کل سایت. صفحه‌ی اپ‌ها با آدرس‌هایی مثل `#app-eggtimer` و `#privacy-eggtimer` باز می‌شن.
- `assets/eggtimer-icon.png`: آیکون تخم‌مرغ‌پز
- `privacy/eggtimer.html`: صفحه‌ی مستقل حریم خصوصی تخم‌مرغ‌پز (همون فایلی که خودت دادی، بدون تغییر).
  لینک استورها رو به این بده: `https://orandapp.ir/privacy/eggtimer.html`
- `og.png`، `robots.txt`، `sitemap.xml`: پیش‌نمایش لینک و سئو
- `404.html` و `.nojekyll`

فایل APK اینجا نیست و نباید توی این ریپو بره (`.gitignore` هم جلوشو می‌گیره). کلید امضا (keystore) و رمزهاش هم هیچ‌وقت نباید تو گیت‌هاب بره.

## گذاشتن روی GitHub Pages
1. فایل‌ها رو (با پوشه‌های `assets` و `privacy` و فایل مخفی `.nojekyll`) تو ریپو آپلود کن.
2. Settings، بعد Pages. Source رو بذار `Deploy from a branch`، شاخه‌ی `main` و پوشه‌ی `/ (root)`.

## وقتی دامنه‌ی orandapp.ir تایید شد
1. فایلی به اسم `CNAME` بساز که فقط یه خط داره: `orandapp.ir`
2. رکوردهای DNS رو طبق مستندات رسمی GitHub Pages (بخش custom domain) تنظیم کن.
3. تو Settings، بعد Pages، دامنه رو وارد کن و HTTPS رو روشن کن.

## وقتی اپ منتشر شد
- تو `index.html` دنبال `APPS` بگرد. دکمه‌ی «به‌زودی تو استورها» (کلید `store` توی `U`) رو با لینک دانلود واقعی عوض کن، یا بگو من عوضش کنم.
- هر آپدیت رو تو `log:[]` همون اپ اضافه کن تا تو «چی عوض شده؟» نشون داده بشه.
- آدرس ایمیل اپ (`MAIL`) فعلاً `orandapp.ir@gmail.com` هست، مثل متن حریم خصوصی. بقیه‌ی سایت `hello@orandapp.ir` رو نشون می‌ده. قبل از انتشار یکی‌شون کن.
